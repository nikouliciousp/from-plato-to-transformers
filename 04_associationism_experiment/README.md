# 📚 Associationism Experiment — Οι 4 Νόμοι του Αριστοτέλη

**Από τη Συνειρμική Μνήμη (350 π.Χ.) στα σύγχρονα Transformers**

## 📌 Τι μαθαίνεις

Ο Αριστοτέλης περιέγραψε **τέσσερις νόμους** για το πώς μαθαίνει ο νους. 23 αιώνες αργότερα, ακριβώς αυτοί οι νόμοι βρίσκονται στα σύγχρονα μοντέλα:

### 🔗 Νόμος της Γειτνίασης → **Hebb's Rule**
"Όταν δύο πράγματα συμβαίνουν κοντά, ο νους τα συνδέει"
- **ML:** `∂w/∂t = η·(y - ŷ)·x`

### 🔁 Νόμος της Συχνότητας → **Gradient Descent**
"Όσο πιο συχνά βιώνονται μαζί, τόσο ισχυρότερη η σύνδεση"
- **ML:** Επανάληψη → επικαιροποίηση βαρών

### 🎯 Νόμος της Ομοιότητας → **Embeddings / Cosine Similarity**
"Η σκέψη ενός πράγματος πυροδοτεί τη σκέψη ενός όμοιου"
- **ML:** `similarity = cos(v₁, v₂)`

### ⚡ Νόμος της Αντίθεσης → **Contrastive Learning (SimCLR, CLIP)**
"Το να δεις κάτι φέρνει την ανάμνηση του αντιθέτου"
- **ML:** Pull similar, push opposite
