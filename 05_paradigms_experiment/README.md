# 🏛️ Paradigms Experiment — 5 Τρόποι Σκέψης

**Ίδιο πρόβλημα, πέντε διαφορετικές φιλοσοφικές προσεγγίσεις**

## 📌 Τι μαθαίνεις

Ένα πρόβλημα διάγνωσης (καρδιακός κίνδυνος) λυμένο με 5 διαφορετικά παραδείγματα:

### 1️⃣ **Προτασιακό** (Parmenides)
- If-Then κανόνες
- "Αν age > 60 → κίνδυνος"
- **Πλεονέκτημα:** Εξηγήσιμο
- **Μειονέκτημα:** Άκαμπτο

### 2️⃣ **Κατηγορηματικό** (Aristotle)
- ∀x: Predicate Logic
- "∀ασθενείς: age∧bp∧chol → risk"
- **Πλεονέκτημα:** Γενικεύσιμο
- **Μειονέκτημα:** Δύσκολο να γραφτούν όλοι οι κανόνες

### 3️⃣ **Συναρτησιακό** (Leibniz) — Neural Networks
- f∘g∘h: Σύνθεση μετασχηματισμών
- Hidden layers με activation functions
- **Πλεονέκτημα:** Υψηλή ακρίβεια
- **Μειονέκτημα:** Black box

### 4️⃣ **Πιθανολογικό** (Hume)
- P(risk|data) = P(data|risk)·P(risk)/P(data)
- Naive Bayes
- **Πλεονέκτημα:** Δίνει πιθανότητες με αβεβαιότητα
- **Μειονέκτημα:** Υπόθεση ανεξαρτησίας

### 5️⃣ **Επαγωγικό** (Epicurus)
- k-Nearest Neighbors
- Μάθε από παραδείγματα χωρίς θεωρία
- **Πλεονέκτημα:** Αυτόματη μάθηση
- **Μειονέκτημα:** Αργό σε μεγάλα δεδομένα

## 🎮 Πώς παίζεις

1. Κούνα τα sliders για ηλικία, πίεση, χοληστερίνη
2. Δες πώς κάθε μοντέλο παίρνει διαφορετική απόφαση
3. Σύγκρινε τους δείκτες: Accuracy, Precision, Recall, F1
4. Δες τα decision boundaries με radar chart

## 📊 Μετρικές Αξιολόγησης

- **Accuracy:** % σωστών συνολικά
- **Precision:** Από τα ΝΑΙ, πόσα ήταν σωστά
- **Recall:** Από τα πραγματικά ΝΑΙ, πόσα βρήκε
- **F1 Score:** Αρμονικός μέσος

## 🏛️ Κεντρικό συμπέρασμα

**Δεν υπάρχει "καλύτερο" μοντέλο παντού.**

Η ερώτηση δεν είναι "ποιο παράδειγμα είναι καλύτερο;" αλλά:
**"Ποια δομή έχουν τα δεδομένα μου και ποιο παράδειγμα ταιριάζει;"**
