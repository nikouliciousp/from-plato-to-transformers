## 🎯 What It Shows

In his work *On Memory and Recollection* (350 BC), Aristotle formulated three laws of association plus the law of frequency. 23 centuries later, the same four laws sit at the heart of machine learning. Each law has its own interactive demo.

| Aristotle's Law | Modern ML |
|---|---|
| **Contiguity** | Hebb's Rule — "fire together, wire together" |
| **Frequency** | Gradient descent — weight updates |
| **Similarity** | Embeddings / cosine similarity |
| **Contrast** | Contrastive learning (SimCLR, CLIP) |

## 🎛 Features

- 4 interactive demos, one per law, with live sliders and canvas animations
- An everyday example for each law
- Summary tab with full mapping and connection to the series
- Bilingual 🇬🇧 / 🇬🇷 · Responsive · Zero dependencies
