## 🎯 What It Shows

The same problem — **cardiac risk** from age, blood pressure, cholesterol — solved by 5 different thinking paradigms simultaneously. The user moves sliders and watches each model change its decision live.

| Paradigm | ML Model | Philosopher |
|---|---|---|
| **Propositional** | Rule-based (if-then) | Parmenides |
| **Predicate** | Predicate logic | Aristotle |
| **Functional** | Neural Network | Leibniz |
| **Probabilistic** | Naive Bayes | Hume |
| **Inductive** | k-Nearest Neighbours | Epicurus |

## 🎛 Features

- 5 models, live decision with confidence bar
- **Evaluation metrics**: Accuracy, Precision, Recall, F1, Interpretability
- Radar chart comparison · 5 decision boundaries
- 🏆 Highlight on the best F1
- Tabs: Experiment · Mathematics · Philosophy
- Bilingual 🇬🇧 / 🇬🇷 · Responsive · Zero dependencies

## 🔬 The Core Lesson

There is no single "best" model. Depending on the problem you optimise a different metric — Recall for medical diagnosis, Precision for spam detection.
