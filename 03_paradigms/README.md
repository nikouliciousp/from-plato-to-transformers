## 🎯 What It Shows

The same problem — **cardiac risk** from age, blood pressure, cholesterol — solved by 5 different thinking paradigms simultaneously. The user moves sliders and watches each model change its decision live.

| Paradigm | ML Model | Philosopher |
|---|---|---|
| **Propositional** | Rule-based (if-then) | Parmenides |
| **Predicate** | Predicate logic | Aristotle |
| **Functional** | Neural Network | Leibniz |
| **Probabilistic** | Naive Bayes | Hume |
| **Inductive** | k-Nearest Neighbours | Epicurus |

## 🎛 Features

- 5 models, live decision with confidence bar
- **Evaluation metrics**: Accuracy, Precision, Recall, F1, Interpretability
- Radar chart comparison · 5 decision boundaries
- 🏆 Highlight on the best F1
- Tabs: Experiment · Mathematics · Philosophy
- Bilingual 🇬🇧 / 🇬🇷 · Responsive · Zero dependencies

## 🔬 The Core Lesson

There is no single "best" model. Depending on the problem you optimise a different metric — Recall for medical diagnosis, Precision for spam detection.

# 🧩 Paradigms Experiment (Ελληνικά)
### 5 Παραδείγματα Σκέψης — Πώς διαφορετικές λογικές λύνουν το ίδιο πρόβλημα

> *Το ML δεν είναι ένα παράδειγμα — είναι η επιλογή του κατάλληλου παραδείγματος για κάθε δομή δεδομένων.*

## 🎯 Τι Δείχνει

Το ίδιο πρόβλημα — **κίνδυνος καρδιακού επεισοδίου** από ηλικία, πίεση, χοληστερίνη — λυμένο με 5 διαφορετικά παραδείγματα σκέψης ταυτόχρονα. Ο χρήστης κουνά sliders και βλέπει live πώς το κάθε μοντέλο αλλάζει απόφαση.

| Παράδειγμα | Μοντέλο ML | Φιλόσοφος |
|---|---|---|
| **Προτασιακό** | Rule-based (if-then) | Παρμενίδης |
| **Κατηγορηματικό** | Predicate logic | Αριστοτέλης |
| **Συναρτησιακό** | Neural Network | Leibniz |
| **Πιθανολογικό** | Naive Bayes | Hume |
| **Επαγωγικό** | k-Nearest Neighbours | Επίκουρος |

## 🎛 Χαρακτηριστικά

- 5 μοντέλα, live απόφαση με confidence bar
- **Δείκτες αξιολόγησης**: Accuracy, Precision, Recall, F1, Interpretability
- Radar chart σύγκρισης · 5 decision boundaries
- 🏆 Highlight στο καλύτερο F1
- Καρτέλες: Πείραμα · Μαθηματικά · Φιλοσοφία
- Δίγλωσσο 🇬🇷 / 🇬🇧 · Responsive · Μηδενικές εξαρτήσεις

## 🔬 Το Κεντρικό Δίδαγμα

Δεν υπάρχει «καλύτερο» μοντέλο παντού. Ανάλογα με το πρόβλημα βελτιστοποιείς διαφορετικό δείκτη — Recall για ιατρική διάγνωση, Precision για spam detection.
