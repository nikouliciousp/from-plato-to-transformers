📌 Κοινό σε όλα τα δίκτυα: Output layer = σ(z) — Sigmoid για binary classification (έξοδος 0-1). Η σύγκριση αφορά μόνο την activation function του hidden layer.
Γραμμικό Hidden Layer
Χωρίς activation, οσαδήποτε layers κι αν βάλεις, το αποτέλεσμα είναι πάντα ευθεία. Τρία layers = ένα layer.
z¹ = W¹·x + b¹ // hidden — καμία activation, απλός γραμμικός μετασχηματισμός
ŷ = σ(W²·z¹ + b²) // output — Sigmoid για 0-1 (κοινό και στα 3 δίκτυα)
Γιατί αποτυγχάνει
W₂·(W₁·x) = W_eff·x  →  πάντα γραμμικό, ανεξαρτήτως βάθους
✅ Πλεονέκτημα
Γρήγορο, σταθερό gradient
⚠ Μειονέκτημα
Μόνο ευθείες — αδύνατο για XOR, κύκλο, σπείρα
ReLU Hidden Layer
Απλό cut στο μηδέν. Η ασυνέχεια της παραγώγου στο 0 δημιουργεί "γωνίες" που φτιάχνουν καμπύλες.
a¹ = ReLU(W¹·x + b¹) = max(0, W¹·x + b¹) // hidden — παράγωγος = 1 αν z>0, αλλιώς 0
ŷ = σ(W²·a¹ + b²) // output — Sigmoid (κοινό)
Παράγωγος — Backprop
ReLU'(z) = 1 αν z > 0  |  0 αν z ≤ 0
Η παράγωγος είναι ασυνεχής στο z=0 — "γωνία". Πλεονέκτημα: δεν εξαφανίζεται. Μειονέκτημα: dead neurons αν z≤0 πάντα.
✅ Πλεονέκτημα
Γρήγορο, δεν εξαφανίζεται gradient, μη-γραμμικό
⚠ Μειονέκτημα
Ασυνεχής παράγωγος στο 0, dead neurons
Sigmoid Hidden Layer
Ομαλή S-καμπύλη, παντού παραγωγίσιμη. Διατηρεί τη συνέχεια. Αλλά η παράγωγός της → 0 για μεγάλο |z|.
a¹ = σ(W¹·x + b¹) = 1 / (1 + e^(−z¹)) // hidden — παντού λεία, παράγωγος = σ(z)·(1−σ(z))
ŷ = σ(W²·a¹ + b²) // output — Sigmoid (κοινό)
Παράγωγος — Vanishing Gradient
σ'(z) = σ(z)·(1−σ(z))  →  max = 0.25 στο z=0
σ'(z) → 0 όταν |z| → ∞
Παντού συνεχής και λεία — αλλά η παράγωγος μικραίνει γρήγορα. Σε βαθιά δίκτυα τα πρώτα layers "παγώνουν".
✅ Πλεονέκτημα
Παντού λεία, συνεχής παράγωγος, μη-γραμμική
⚠ Μειονέκτημα
Vanishing gradient — μαθαίνει πολύ αργά σε hidden layers

GELU — Το Καλύτερο και των Δύο
GELU(x) = x · Φ(x)
Ομαλή όπως η Sigmoid + γρήγορη όπως η ReLU. Χρησιμοποιείται στους Transformers (GPT, BERT, Claude). Η επόμενη εξέλιξη.
Η ΦΙΛΟΣΟΦΙΚΗ ΑΝΤΙΣΤΟΙΧΙΑ

Τρεις αρχαίοι Έλληνες φιλόσοφοι είχαν ήδη περιγράψει τρεις διαφορετικές θεωρίες για τη φύση της πραγματικότητας. Κάθε μία αντιστοιχεί σε μία activation function.

—
Παρμενίδης → Γραμμικό
"Το ον είναι και δεν μπορεί να μη είναι" — ένας αμετάβλητος, στατικός κόσμος
ML ΑΝΤΙΣΤΟΙΧΙΑ
z = Wx + b  →  μόνο ευθείες, αμετάβλητη γραμμικότητα
Ο Παρμενίδης έβλεπε έναν κόσμο χωρίς αλλαγή. Το γραμμικό δίκτυο κάνει το ίδιο — βλέπει μόνο γραμμικές σχέσεις, ανεξαρτήτως βάθους.
∿
Ηράκλειτος → ReLU
"Τα πάντα ρει, ουδέν μένει" — απότομη αλλαγή, γωνίες, ρήξη
ML ΑΝΤΙΣΤΟΙΧΙΑ
ReLU(x) = max(0,x)  →  απότομη γωνία στο 0, ασυνεχής παράγωγος
Ο Ηράκλειτος πίστευε στην απότομη αλλαγή — τα πάντα ρέουν, τίποτα δεν μένει σταθερό. Η ReLU ενσαρκώνει αυτό: απότομο cut στο 0, ασυνεχής παράγωγος. Γρήγορη, αποτελεσματική, αλλά "σκληρή".
∫
Αριστοτέλης → Sigmoid
"Η φύση δεν κάνει άλματα" — ομαλές μεταβάσεις, συνέχεια, σταδιακή αλλαγή
ML ΑΝΤΙΣΤΟΙΧΙΑ
σ(x) = 1/(1+e⁻ˣ)  →  παντού λεία, συνεχής παράγωγος
Ο Αριστοτέλης πίστευε ότι η φύση κινείται ομαλά, χωρίς άλματα. Η Sigmoid είναι ακριβώς αυτό — παντού λεία, συνεχής παράγωγος. Αλλά η ομαλότητα έχει κόστος: vanishing gradient.
⊕
Leibniz → GELU (η επόμενη εξέλιξη)
"Ο κόσμος είναι το καλύτερο δυνατό σύνολο αντιθέτων σε αρμονία"
ML ΑΝΤΙΣΤΟΙΧΙΑ
GELU(x) = x·Φ(x)  →  ομαλή ReLU — Transformers
Ο Leibniz ήθελε την αρμονία των αντιθέτων. Το GELU το πετυχαίνει: ομαλό όπως η Sigmoid + αποτελεσματικό όπως η ReLU. Αυτό χρησιμοποιούν σήμερα GPT, BERT, Claude.
